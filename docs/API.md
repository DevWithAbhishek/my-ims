# API

## Checks before Design

```

    PRD requirement
        ↓
    Who can call it?
        ↓
    Resource / command
        ↓
    HTTP method + path
        ↓
    Request contract
        ↓
    Validation
        ↓
    Authorization
        ↓
    Business rules
        ↓
    Transaction boundary
        ↓
    Response
        ↓
    Error contract
        ↓
    Concurrency / idempotency
        ↓
    OpenAPI
        ↓
    Implementation

```
